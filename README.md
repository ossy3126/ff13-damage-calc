# FF13 ダメージ計算機

ファイナルファンタジーXIII のダメージを計算するWebツールです。
与ダメージ（味方→敵）と被ダメージ（敵→味方）を計算できます。

## 使い方

画面上部のタブで、2つの計算を切り替えます。

* **与ダメージ（味方→敵）**：味方の攻撃が敵に与えるダメージ
* **被ダメージ（敵→味方）**：敵の攻撃が味方に与えるダメージ

結果は「最大」「平均」「最小」（複数ヒットは合計）で、画面の上に固定して表示されます（下にスクロールしても見えます）。いちばん下の「計算の内訳」で、計算の各工程の途中経過を確認できます。

入力した内容はブラウザに自動で保存され、次に開いたときもそのまま残ります。「入力を初期値に戻す」で最初の状態に戻せます。

### 与ダメージ

1. プリセットで技を選びます（たたかう、ルイン、ブロウ、ルーラーフィスト、召喚獣の技など）。タイプ・倍率・変動幅・ヒット数が自動で入ります。
2. 攻撃力（物理攻撃力／魔法攻撃力）を入力します。召喚獣は、ランクを選ぶと攻撃力が入ります。
3. 攻撃側の補正（ブレイブ／フェイス、チェーンボーナス、ロール、ダメージ限界突破など）を設定します。
4. 防御側で「対象の敵」を選ぶと、物理・魔法耐性と対象のHP（最大HP）が入ります（→[対象の敵](#対象の敵)）。敵を選ばずに、耐性を手で設定することもできます。
5. プロテス／シェル、デプロテ／デシェル、ダル状態などを設定します。
6. 対象のHPが入っていると、撃破までの回数が表示されます。

### 対象の敵

* 1〜13章の敵（289体）から選べます。章ごと（11章は地域・ミッションごと）に並んでいて、「敵を探す」に名前の一部（ひらがな・英語名でも可）を入れると絞り込めます。
* 「技の属性」（火・氷・雷・水・風・土）を選ぶと、その敵のその属性の耐性が入ります。サンダガやブリザドのように属性が1つに決まっているプリセットは、自動で合わせます。
* バルバロイなどブレイクで耐性が変わる敵は、「敵がブレイク中」にチェックすると、ブレイク後の耐性に切り替わります。
* ガードを使う敵（シド・レインズ、PSICOM強襲兵、聖府親衛猟兵）は、「ガード中」にチェックすると、ダメージを90%減らして計算します。
* 自分にデプロテ・デシェルをかける敵（ウシュムガル1回目のオーバードライブ後、プラウド・クラッド2回目のリミッター解除後）は、自動でチェックが入ります。
* 敵を選んだあとでも、耐性やHPは手で変えられます。

### 召喚獣のフィニッシュ技

* オーディンの斬鉄剣、シヴァのダイヤモンドダスト、ヘカトンケイルのガイアサルヴォーを選ぶと、フィニッシュ前の連続ヒットによるチェーンボーナスの上昇を含めて計算します。
* 「チェーンボーナス」欄には、撃つ直前の値を入れます。敵のチェーン耐性、ブレイク値、撃つ前からブレイク中かどうかも設定できます（対象の敵を選んでいれば、チェーン耐性とブレイク値は入っています）。
* 斬鉄剣は、敵の最大HPと、斬鉄剣までに与えたダメージ（`1520+3300` のように足し算で入力）を入れると、一撃で倒せるかどうかを判定します。

### 被ダメージ

1. 敵と敵の技を選ぶと、攻撃力・タイプ・倍率・変動幅・ヒット数が自動で入ります。「敵を探す」に名前の一部（ひらがなでも可）を入れると絞り込めます。
2. 防御側で、装備の耐性（％）、プロテス／シェル、ディフェンダーのロール、ガード行動、エリアバリアなどを設定します。
3. エリアバリアは、「ダメージを受けるキャラ」で「巻き込まれた味方」を選んだときだけ効きます。
4. 連鎖アビリティによる軽減（−5〜−30）は、1ヒットごとにかかります。

### 手動入力

プリセットや敵を選ばずに、攻撃タイプ・攻撃力・倍率・変動幅・ヒット数を直接入力することもできます。

* 倍率：ヒットごとに違う場合は `+` でつなぎます（例：`0.1+3.5`）。同じ倍率が続く場合は `*` で回数を書きます（例：`0.25*2+0.5`）。属性のあるヒットは末尾に `e` を付けます（例：`0.25*2+0.25*5e`）。
* ばらつき幅（変動幅）：ヒットごとに違う場合は、倍率と同じ書き方です（例：`98*19+9`）。
* 属性耐性は、属性のあるヒットにだけ適用されます。
